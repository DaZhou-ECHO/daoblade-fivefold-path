# D09 音效与声音反馈

状态：策划草案。依赖 D01 BattleEvent，不依赖特效播放完毕。

## 已有内容

playHitSound 已提供可关闭的 Web Audio 命中/完美格挡合成音。后续是补分层与覆盖，不是从零引入必须联网的声音服务。

## 初版声音清单与优先级

| 优先级 | 声音 | 用途 |
|---|---|---|
| 先做 | 挥剑、实际命中、格挡、完美格挡、受击 | 分辨动作是否发生及其结果 |
| 再做 | 剑气发射、主动技能准备/施放、怪物危险前摇、死亡 | 预警、力度、技能身份 |
| 后做 | 灵珠获得/有效成式、检查点、菜单确认 | 成长与流程反馈 |
| 最后 | 五境低强度环境音和简短背景音乐 | 氛围；不是初版战斗验收的前置条件 |

国风可以通过适当木石、金属、风水质感与节制音乐表达，不应把所有攻击都做成巨响、锣鼓或长吟唱。敌人威胁音与玩家技能音要可区分，不能被同频连续播放淹没。

## 播放规则

- 每次事件有唯一标识，暂停或重绘不重复播放；命中音依据命中结果，不依据挥剑动画。
- 同类声音有并发上限、短间隔和轻微变化；首领预警优先于无关环境音。
- 建议提供总音量、战斗音效和环境/音乐的分量控制，以及静音；关闭声音仍须保留视觉提示。
- 浏览器需要用户交互后才能启动声音的情形应有正常交互路径；资源失败不阻断战斗。失焦/隐藏时按统一暂停策略处理声音。
- 素材本地保存，来源和授权可追踪；不抓取商业游戏音频。初期可以沿用合成音作可靠底座。

## 首轮与验收

仅做一项基础剑招的挥空→命中→格挡→完美格挡四类对比。验收事件只播一次、音量可控、多人怪物同屏不爆音、暂停/静音/重试正确；听觉提示与实际有效阶段一致。记录实际使用的合成方式或授权素材，不能把“有占位声音”写成五境音频完成。
