# D05 敌人与首领

状态：策划草案。依赖 D02 的受击/动作判定与 D06/D07 的遭遇、空间锚点。

## 接续现状

五境目前各4名近战、1名远程、1名首领。火境已有较完整的前摇→攻击→恢复、冲锋/火球/剑波及近身攻击并发限制；其余境较多共用追击/投射物。怪物主要由 Canvas 绘制。应提炼已有行为能力，不能五境分别重写一套AI。

## 初版控制规模

采用有限行为骨架：追击近战、持势重击、牵制远程，首领在这些动作上形成两种清楚应对方式。初版近战仍占多数；先追求“看懂后会应对”，再扩充怪物数量和模型。

每个敌人必须说明：发现/追击范围、攻击距离、前摇提示、有效阶段、恢复空当、受击/硬直与离开战斗规则。多个近战围攻时，限制无预警同时出手；远程与近战组合要给玩家反应空间。

## 五境差异提案

| 元素 | 独有威胁方向 | 玩家学习点 |
|---|---|---|
| 木 | 近战纠缠＋短时束缚区域 | 控制距离、及时离开区域 |
| 火 | 明显蓄势突进＋爆发 | 读前摇、闪避后抓恢复 |
| 土 | 缓慢重击＋正面防御 | 换位、反击，不持续硬砍 |
| 金 | 直线穿刺＋短后退重整 | 避开直线、接近时机 |
| 水 | 延迟攻击＋短时减速 | 区分提示与真正命中时刻 |

以上是原创战斗提案，不是经典文献的怪物能力记载。无论玩家修什么五行，都应有基础应对办法；不能让某关只能靠特定元素解除必死机制。

## 首轮与边界

先验收一类近战的完整循环，再为样板关做一个首领的两招；不同时制作五套首领和大量稀有敌人。本方向拥有敌人行为/攻击定义；关卡决定摆放与组合，地图提供可行走空间，美术按已定义阶段绘制。

验收：每招都有可识别提示与空当；不会因玩家站高台完全失去行为，也不会穿地追击；死亡敌人停止攻击；特效和声音缺失不影响判定；一个基础配置能通过样板遭遇。数值平衡和素材升级分别记录，不把换颜色算新敌人机制。
