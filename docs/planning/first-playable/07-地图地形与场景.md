# D07 地图地形与场景

状态：分阶段实施。031已本地实现五境机关不同周期、就地倒计时、地面高度避险及基础单跳验证；主支路独立体验与完整可达性仍待实施。负责“空间在哪里、如何通过”，与 D06 的教学、遭遇、胜败和奖励分开。

## 接续现状

五境已有背景、每境5个平台、2祭坛、2危险区，世界宽度统一3200，主地面连续。不是空白地图，但差异主要是配置坐标与画面；还没有证明形成五种不同探索体验。

## 建议分三层做，避免放在一起改

1. **地形灰盒**：地面/平台/落点/主支路/检查点锚点、相机边界和可通行性。不做复杂背景细节。
2. **空间可读性**：出口方向、支路提示、危险区、遮挡和远近层次。碰撞和装饰分开，装饰不决定能否站立。
3. **场景美术**：远景/中景/前景、地方材质、国风建筑意象、环境动态。美术轮不得偷偷挪平台或更改跳跃距离。

## 五境空间差异提案

| 地图 | 空间主题 | 首版特色 | 不宜采用 |
|---|---|---|---|
| 木境 | 林间山径、根桥、少量高差 | 入门路径清楚，侧上方支路 | 满屏藤叶遮住敌人 |
| 火境 | 熔岩山口、炉台、宫阙远影 | 有安全观察位的周期危险段 | 红色特效与危险区无法区分 |
| 土境 | 山门、石阶、遗迹院落 | 宽窄空间转换、重击躲避区 | 只能靠高防御硬吃伤害 |
| 金境 | 剑冢、矿脉、石制廊道 | 直线威胁与侧向躲避空间 | 全程狭廊导致无法闪避 |
| 水境 | 寒潭、栈道、临水楼阁 | 路径折返视觉、延迟机关 | 初版即加入复杂游泳物理 |

场景为原创构图；新增具体小场景时单独维护“资料名称/原文位置/借用意象/原创改编”四列来源表。现有文化取材表不能自动证明这些新场景已有古籍依据。

## 主路与支路约束

全部主路必须用基础移动、单跳、基础剑术完成；巽卦二段跳、特定主修或新技能只能增加便利或可选奖励。支路要能返回，不让可拆换测试构筑或未来永久构筑造成软锁。

检查点、首领入口、出口由稳定ID定位；移动锚点前与关卡文档核对。陷阱有提示、安全落点与恢复路径，不以盲跳和画外偷袭制造难度。

## 首轮与验收

先做样板关一段主路＋一条支路的灰盒，测实际跳跃可达性；再扩展整关，最后制作背景。自动可达性检查不能替代真实试玩。验收双向返回、基础配置通行、支路不死锁、敌人出招有站位空间、不同视口能看清前方危险；帧率和加载情况需在目标笔记本实际记录，不能只看截图。
