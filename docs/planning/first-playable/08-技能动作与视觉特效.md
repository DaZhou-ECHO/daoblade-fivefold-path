# D08 技能动作与视觉特效

状态：策划草案。依赖 D01动作/事件、D02判定、D03编译后的有效技能，身体姿态素材由 D04 提供。

## 当前基础与缺口

已有剑轨、粒子、直线/圆环技能反馈及五行颜色。八卦主动技能能使用，但 skillPose 与同一精灵渲染器之间还没有形成八技能专属身体动作；很多效果主要靠 qiCast 和通用图形。不能说完全没有特效，也不能认为已有专属动作全部完成。

## 把一个技能拆成四层交付

1. **准备动作**：身体重心、持剑方向与短前摇，先看清“要做什么”。
2. **施放主体**：剑轨、发射点、阵式或波纹，与实际判定阶段同步。
3. **命中反馈**：受击闪光、方向、格挡/破防区别，只响应真实命中事件。
4. **收势恢复**：剑回握点、残留消散、回基础动作；结束不能卡住输入。

初版先用刺击、斩击、踏地、守式、吐纳等有限身体动作族服务八卦技能，再用不同机制和元素形状形成区别；不承诺为所有珠子顺序画独立动画。

## 五行可辨识性

| 五行 | 轮廓与运动建议 | 需要看懂的信息 |
|---|---|---|
| 金 | 收束直线、薄刃、短促碎屑 | 穿透方向和触点 |
| 木 | 分枝弧线、短时生长/回流 | 持续或恢复的生效位置 |
| 水 | 层叠波纹、流动拖尾、冷凝边缘 | 控制区域和延迟时机 |
| 火 | 向外/向上的短爆发、余烬 | 爆发范围与留存灼烧区别 |
| 土 | 厚重轮廓、低位尘粒、稳定盾面 | 守御边界和冲击位置 |

这些是游戏化视觉规则，不能作为古籍原文描述。已有文化取材继续沿用；新意象单独补可核验来源。

## 与符文组合衔接

只读取 D03 的有效结果，例如该技能核心元素、一个主要修饰、机制标识、效力档。无效组合不播放假共鸣；多个珠子的粒子不能全部无上限叠加。用户已选择各卦技能独立取核心元素，全身外观另选主要阵式：金属外观的角色施放坎水技能是合法表现，不能强行把所有技能改成外观色。技能元素与卦位本位限制的检查由成长方向统一完成。

## 首轮与验收

首轮只做一个技能完整四层，包含有/无有效符文变化的对比。检查双向、地面/空中、受击打断、连放与结束恢复；粒子不遮住敌方前摇，关闭震屏仍看得懂。关闭特效或加载失败后，伤害、命中、消耗和冷却必须相同。记录目标机器同屏压力表现，先复用/限制对象数量再考虑复杂渲染技术。
