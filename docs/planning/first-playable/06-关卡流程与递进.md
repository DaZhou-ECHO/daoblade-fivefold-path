# D06 关卡流程与递进

状态：分阶段本地实施。021–022已接新阵盘五境选择、目标/剑碑/恢复与结算，实际完整通关和平衡仍待验收；见[本地进度](../../implementation/本地功能进度.md)。用户已确认：一张完整样板关→逐张扩展五境；推荐路线递进，已开放秘境可自由重玩。负责“玩家这一关经历什么”，不与地图美术混写。

## 当前缺口

现有五境可选关、战斗、击败首领、结算获得珠子，但主要是固定6敌＋连续主路。本地已补新阵盘五境中途检查点和分段目标，但完整流程与实战平衡仍在验证；8–12分钟是先前目标，不是当前实测结果。

## 样板关五段结构

| 阶段 | 体验目的 | 设计约束 |
|---|---|---|
| 入境 | 看懂本关目标，安全试招 | 简短提示，不在第一次落地同时遭多敌攻击 |
| 学习段 | 认识一种敌人或机关 | 单独展示，给观察和反应机会 |
| 变化段 | 支路、奖励、敌人组合 | 1–2条可选支路；不是每关相同高台换背景 |
| 检查点与综合段 | 恢复、整理，然后验证刚学内容 | 检查点位置清楚；禁止重复领取同一试炼奖励 |
| 首领与结算 | 应对本关主题，反馈构筑效果 | 可读招式与恢复空当；结算后能重试/调整配置 |

先用火境验证完整结构，之后每次只迁移一境。首领不是单纯血量更高的小怪；采用有限招式组合即可，初版不强求复杂多阶段演出。

## 推荐挑战顺序与开发顺序分离

建议玩家推荐路线暂为木→火→土→金→水：入门移动与距离→爆发预警→守势与换位→直线威胁→延迟节奏。这是难度教学提案，不是属性克制链或已经核验的历史修行次序。

开发先做火境，玩家可先看木境的推荐标签。建议沿用当前已开放关卡，不因新路线重新锁住旧档；未来若需要强制解锁，另作产品决定。任何五行构筑都应能完成主路，不能要求必须按推荐路线取得某珠。

## 检查点、重玩与奖励

建议初版一处检查点，只保存最小试炼状态：试炼ID、规则/配置快照、检查点ID、已领取奖励标记、必要进度。刷新后恢复至检查点，不恢复到离线前的某个挥剑帧；具体字段由 D01/D10设计。

死亡后“从检查点继续”与“重新开始本关”要明确区分。检查点之后的战斗可按规则重置，但已领祭坛和宝箱不能再次发奖；同一试炼只结算一次。完整重开产生新试炼，正常复玩可以获奖。首通额外奖励和普通重玩奖励可分开设计，不能通过重试刷新反复领取首通奖励。

检查点续玩不能在战斗快照中途更换珠子；想调整构筑，先结束/放弃本次试炼再开始新试炼，避免配置与进度不一致。

## 边界与首轮

D06 定义阶段、遭遇/检查点ID、成功条件和奖励语义；D07 提供位置锚点；D05 提供敌人模板；D10保存最小进度。本方向不画角色帧，不改基础跳高。

首轮用灰盒做完整流程及检查点语义，不急于填满背景。验收从新存档走到结果、失败续关、完整重开、刷新恢复、重复领取检查；记录真实时长和卡点。仅胜利测试通过、仅截图或仅配置了一个检查点，都不代表整关完成。
