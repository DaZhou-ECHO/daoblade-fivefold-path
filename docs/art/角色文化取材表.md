# 角色文化取材表

核验日期：2026-10-20。原典提供文化意象；服装、珠子、八卦成长和技能数值均为原创游戏设计。未据小说复用角色、门派或武器。

| 设计依据 | 原典或官方资料及实际内容 | 游戏取用与边界 |
|---|---|---|
| 五行性质 | [《尚书·洪范》](https://ctext.org/shang-shu/great-plan/zhs)：水润下、火炎上、木曲直、金从革、土稼穑 | 为轮廓与粒子提供方向。金穿透、木回复等是游戏设计，不是原典技能规定。 |
| 五色 | [《礼记·月令》](https://zh.wikisource.org/zh/%E7%A6%AE%E8%A8%98/%E6%9C%88%E4%BB%A4)：各时令的服色、玉色与木火土金水相联，金白、水黑 | 主色金白木青水玄黑火赤土黄；水蓝是高光。原文是礼制语境，不是古代道士的五套战斗制服。 |
| 八卦身体取象 | [《周易·说卦》](https://ctext.org/book-of-changes/shuo-gua)：乾首、坤腹、震足、巽股、坎耳、离目、艮手、兑口 | 对应配饰位置属于游戏改编；兑口映射领口吐纳珠、离目映射技能高光均非传统法服规制。 |
| 束发、簪与衣装 | [中国道教协会《道教服饰》](https://taoist.org.cn/getDjzsById.do?id=288)：冠服、巾帽与簪，并区分日常和仪式衣帔，存在时代、派别差异 | 借取束发簪的文化形象。本轮短袍、红发带和布靴是原创江湖装束；未复制斋醮法服。 |
| 剑与玉器 | [中国道教协会法器资料](https://taoist.org.cn/getDjzsById.do?id=282)：法剑、玉册、玉印等属于宗教仪式器物 | 本命剑参考器物母题；八槽镶珠和元素变形完全原创，不宣称真实法剑存在这套功能。 |
| 镜、玉策 | [《抱朴子·内篇·登涉》](https://ctext.org/wiki.pl?chapter=296571&if=gb)：入山防护叙述中有背镜辨精魅和佩玉策等母题 | 可启发未来探索配饰。缩成腰饰、加入侦察光效是原创；不能把文本法术当作现实效果。本轮未制作此类挂件。 |
| 守静与柔弱 | [《道德经》](https://ctext.org/dao-de-jing/zh)：第十六章的守静、第七十八章的水与柔弱意象 | 可作为安定待机、卸力与水行反馈的审美方向；不是剑术动作复原教程。 |

首轮已使用的文化要素是简洁束发、交领衣装、剑的原创形制与节制配色。五行服装、八卦配饰、显纹—成器—化象仍为后续设计。道协网页正文提取偶有超时，核验使用了官方检索摘要；其余原典核验采用上述原文页面。若后续为特定时代/派别制作服饰，应进一步核对该时代材料，不能把当前原创角色标注为历史复原。
