# 木境怪物与最终 Boss 美术优化

配套实施记录：[052 木境水墨](../implementation/052-木境水墨.md)。本文只讲木境的四个怪物族与最终 Boss「古木守灵」。

|---|---|---|---|---|
| `wood-guard` | 木灵刀卫 | 64×96，脚底 (32,90) | idle 2 / walk 4 / 普攻 3 段 / hurt / death 4 / dash / cast / heavy | 荧光黄绿描边；刀与人一起整体倾斜；深绿背景上轮廓发闷 |

共同点：动作行与帧数齐全、脚底锚点已对齐、死亡是塌缩序列——**时序与碰撞不需要改**，问题集中在材质、轮廓与关键姿态。

## 二、本轮的九项处理

1. **去荧光描边**：把最外层像素向墨色压 46%（Boss 50%），并在最外 1px 上做确定性噪声扰动，避免整圈死黑。
2. **左上受光**：只给“上方或左侧为透明”的边缘像素混入 26%–30% 纸白，形成笔锋式高光，深绿天幕下也能读出轮廓。
3. **叶簇换色**：`g >= r` 的像素按亮度混向苔青（MOSS→SAGE），黄绿高光不再像抠图残边。
4. **树皮克制**：暖褐像素只轻提 2%–5%，不再整体加亮，避免 Boss 变成“红叶树”。
5. **深部收墨**：亮度低于 0.2 的像素混入 36% 墨色，压住碎点噪点。
6. **中间调提亮**：非树皮像素 ×1.12（Boss ×1.16），保证在 `#071d1a → #2f7552` 的天幕上仍有对比。
7. **Boss 关键姿态**：对 `dash_windup/dash_strike/heavy_windup/heavy_strike` 四行做按高度加权的位移——脚底不动，躯干前倾与枝冠摆动分开计算，起手抬枝、重击下压可读。
8. **调色板回收**：普通怪 31 色、Boss 47 色，与 `check_world_art.py` 的上限一致。
9. **锚点不变**：帧尺寸、帧格位置、`foot` 与 `bodyHeight` 全部沿用清单原值，动画映射无需改动。

## 三、Boss 水墨技能时间轴

只覆盖现有三个阶段，不新增技能、不改变数值与判定。

| 阶段 | 视觉 | 实现位置 | 备注 |
|---|---|---|---|
| 前兆/预警（windup） | 脚下墨池由 10px 晕到 36px；面朝方向 3 道短笔触 | `wood-ink.js:drawBossInk` | 与原有黄色前摇标记并存；墨迹只是方向与气氛 |
| 释放（strike） | 沿朝向一笔干笔弧线 + 末端墨点 | 同上 | 弧线长度随进度 26→60px，属于表现参数，不是攻击范围 |
| 命中（hurt） | 五个固定角度的溅墨点 | 同上 | 由既有受击状态驱动，不新增事件 |
| 收尾 | 笔触随 `strike` 进度淡出（alpha 0.30→0.18） | 同上 | 不做全屏墨雾，避免遮挡 Boss 与玩家 |

未做的两个原型：`山水留白`（Boss 消隐再现）与 `枯荣转换`（阶段变色）需要改动 Boss 状态机或阶段判定，按范围要求留待确认。

## 四、验收口径

- 轮廓：在木境天幕下，四个族在 100% 缩放时能分辨形状而不只靠颜色。
- 时序：动画行、帧数与 `manifest.json` 一致；`check_world_art.py` 与 `test_world_art.py` 通过。
- 规则：`git diff` 不含 `game.js`、战斗数值、AI、碰撞、存档与 UI。
- 未验证：真人操作下的手感、实体手机触控、听觉反馈。
