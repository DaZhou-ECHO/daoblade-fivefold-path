# 木境开源素材与许可清单

日期：2026-11-26，任务 052。结论先写：**本轮没有导入任何第三方素材或工具产物**，木境全部资源都由仓库内的 `tools/build_wood_ink_art.py` 从既有原始快照程序化重建，许可归属本项目。下面记录评估过的候选与不接入的理由，供以后需要外部素材时复核。

## 一、评估过的候选

| 名称 | 页面/仓库 | 许可 | 能提供什么 | 结论 |
|---|---|---|---|---|
| PixelFX | https://github.com/patch-gg/pixelfx | 仓库标注 MIT；附带 Patch Pixel 字体另有版权说明，需看 NOTICE | 程序化像素特效（Nature/Weather/Critters/Impacts/Transitions），可导 PNG 序列帧 + JSON | **仅参考**：它是 Node 工具，导入会把构建链捆进来；本轮水墨层用 Canvas 直接绘制即可 |
| PVFX Foundry | https://nerijs.itch.io/pvfx-foundry | CC0 1.0 | 253 种现成像素特效图集（Thorn Wall、Pollen Drift、Fog Bank 等） | **仅参考**：CC0 可用，但素材风格与本项目 32×32 像素密度不一致，需重切与调色，收益不抵风险 |
| Forest Monsters | https://opengameart.org/content/forest-monsters | CC-BY 3.0（需署名） | 眼球、地虫、植物怪等动画 | **不接入**：与现有 20 个怪物家族的动作/锚点规范不同，且引入署名义务 |
| Tileset Platform Forest | https://opengameart.org/content/tileset-platform-forest | CC0 | 32×32 森林模块化图块 | **不接入**：本项目 32px 图块的语义（顶面/单向/填充/装饰）已固定，替换会造成其它四境不一致 |
| Tiled / LDtk | mapeditor.org / ldtk.io | 工具自身 GPL / MIT | 地图编辑器 | **不使用**：本项目地图是 JSON + 程序化绘制，迁移格式属于架构改动 |
| LibreSprite | https://github.com/LibreSprite/LibreSprite | GPL-2.0 | 逐帧绘制/洋葱皮 | **未使用**：本轮由脚本生成，未做手绘帧 |
| WatercolorShader | https://github.com/AleksLitynski/WatercolorShader | 未确认 | 纸张斑驳与晕染 | **仅技术参考**，许可未确认，不接触代码 |
| PD Ink Wash | https://pixeldreamerstudio.itch.io/pd-ink-wash-godot-4 | 付费资源，LITE 另有许可 | 水墨/宣纸/远山/朱印 | **不使用**：付费且面向 Godot 4，本项目为 Canvas |

## 二、本轮真正“接入”的东西

| 资源 | 来源 | 许可 | 说明 |
|---|---|---|---|
| `static/sprites/world-v1/wood-*.png`（10 个） | 由 `tools/build_wood_ink_art.py` 从 [原始快照](wood-v1-legacy/) 重建 | 本项目自有 | 程序化绘制，无外部纹理、无 AI 生成中间件依赖 |
| `static/js/wood-ink.js` | 新写 | 本项目自有 | Canvas 2D 绘制墨池/笔锋/溅墨，未使用着色器 |
| 墨色/纸色/苔色/朱印色板 | 手写常量 | 本项目自有 | `PAPER #e9e7d1`、`INK #141c1a`、`MOSS #6c8a60`、`SEAL #a43a2d` 附近取值 |

## 三、复核规则（以后再用外部素材时）

1. 先查原始页面与仓库的 LICENSE/NOTICE，不只看聚合站标签；CC0、CC-BY、MIT、GPL 不能混用。
2. 任何 CC-BY 素材必须把作者与出处写进本文件与 README，并在游戏内可查。
3. 不导入来源不明、从商业游戏提取或 AI 授权不清的素材。
4. 素材尺寸、透明边缘、pivot 与像素密度必须与现有规范一致，否则改造后才能谈接入。
5. 工具许可与产物许可分开记录：用 GPL 编辑器绘制的美术资源不因此变成 GPL。
