# 024 近敌战况文字
- 目标：让玩家知道最近活敌在左/右、是否身后、气血与当前预警/出招/收招阶段，改善Canvas围攻与转身决策。
- 用户授权：持续玩法优先，不新增美术，仅本地。021–022实际首领战中敌人绕背难看清，不能靠盲目J/Q。
- 范围：game只读近敌投影、HTML/CSS一行功能文字、回归与真实试玩，本Agent独立。
- 不在范围：自动锁定/转身/攻击、伤害与AI改动、屏幕外全图寻敌、绘制新角色/特效。
- 规则：仅最近活敌；超过600距离只提示来向远处，不展示血量/攻击细节；范围内显示真实状态；清场显示已肃清。左右按中心位置，身后按当前朝向，贴身时不强行标左右。
- 验收：死亡/远敌不抢占信息、朝向与阶段正确、不修改战斗对象、实时命中/绕背/收招可读，旧档与新阵盘共用。
- 基线：023 8e0ed74；仍保留全部五境原玩法。
