# 017 试验挑战与成长服务

目标：为新规则火境挑战建立独立、可恢复、一次性结算的服务契约；下个切片接BattleGame与真实挑战入口。
用户要求继续落实配珠→闯关→成长→拆换→保存恢复，所有成果仅本地。
范围：array-lab-v2格式兼容、试炼服务/API、检查点与祭坛记录、原子结算账本、有效珠经验与技能编译成长、已有试验界面兼容；本Agent负责，无并行。
不在本切片：BattleGame正式挑战入口与完整通关验收（紧接018），全八宫、正式境界突破与新随机掉落。不得将服务完成当作可玩挑战已完成。
验收：v1试验档装配原样升级，旧永久档不变；开战冻结有效珠与构筑；检查点/祭坛可恢复且不可重复领取；仅胜利给有效珠每ID一次经验；重复结算/丢响应重试不发第二次奖励；客户端不能改经验或进度；revision与账号隔离；等级只影响对应技能模块，不全局叠加。
试验参数：等级上限3，每级20经验，每胜利20经验＋12试验修为；满级不再累积经验。核心每级只加Q直伤2，聚焰每级只加灼烧1，引爆每级每层加2，留痕每级减Q耗气1。失败/放弃不发经验，检查点失败可保留同一试炼继续。全部为待实测调参的原型值，不写成正式成长定案。
