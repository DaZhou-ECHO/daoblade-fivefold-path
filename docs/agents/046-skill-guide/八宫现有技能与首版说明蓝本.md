# 八宫现有技能与首版说明蓝本

本轮解决选择前不懂用途、装配时不知变化、保存后不知怎么用的问题。正式规则：8宫固定元素、40固定珠、2主动2心法、练气6格筑基10格、每珠1—3级。下表全部为现有能力；不加入新技能树、资源或按键。

五行是本作固定技能元素与珠的归属；八宫是招式及心法；节点决定开通、增强、变式与心法。旧版永久镶嵌的主副属性不套入正式档。显纹/成器/化象及24新节点留作后续独立策划，不作已实现成长。

## 获得、成本与实际结果
- 征程胜利按关卡元素发珠；某境首通补对应核心、纹路和心法，后续优先未持有。重复珠可转经验，满级按现有规则转修为。
- 有效出战珠胜利获得20经验，升一级需20经验，满3级；重复珠经验另计。装配不等于学习付款。
- 基础主动直击18，核心每升一级加2；纹路1—3级加4/5/6；锐式加6/8/10、耗16；流式伤害修正−3/−2/−1、耗8/7/6；基础耗12。基础冷却1.5秒，离/坎心法分别影响直击/冷却。
- 上述是招式直击参数；命中还受实际防御与交互影响。灼烧、护盾、减速等单独说明，不算作同一直接伤害数字。
- 升级、装入、出战、保存是不同操作。师门三系修习仍消耗原有修为，与固定灵珠装配分开。

任意宫都能说明用途、按键、消耗、时机、限制；任意珠都能说明前置、生效与成长；草稿效果和已保存区分，保存成功后回顾。8主动×3等级×3变式直接对真实技能执行核对。实体触控与完整人工战斗结果另记。
