# 技能界面与演示交互规范

## 入口与层级
行旅入口→游客/账号→村落→师父或修行入口。师父仍有八宫、师门修习、筑基心劫三页。桌面左侧环阵与符牌，右侧所选宫用途、主动/心法、图解、五节点和珠匣；手机先看完整环阵，再滚动编辑详情。手机“查看本宫招式”主动滚到说明，不在选宫时强制跳动。

```text
总览：[本命剑＋八宫/用途/出战] [用途→操作→示意→限制]
珠槽：[图形＋等级] [作用/前置/成长] [装入或取下]
保存：[已保存→草稿] [四符牌] [保存回顾→用法/阵盘/山河图]
```

## 状态与反馈
- 未获得可看说明，但不能装入；获得来源按宫位固定元素显示。
- 持有未装、装入未连通、连通未出战、草稿连通、已保存出战分别标记。草稿不自动生效。
- 断联说明指出直接前置；取核心保留子珠，确认显示其能力停用。锐式/流式替换先确认并预览。
- 容量同时显示已装与上限。比较数字不依赖红绿；新增和停用明确写出。
- 数值预览来自服务端。等待显示计算中，失败保留草稿和重试；服务版本冲突不覆盖旧档。
- 主动详情的参数是该宫按当前已连通珠与心法的参考；是否出战单独由符牌决定。心法等级效果不等于当前已生效。

## 演示
480×200画布，复用现有角色渲染；敌人使用简化轮廓。按站位、按键、生效、结果四步播放约5秒，一次结束。显示普通敌人/首领切换，控制差异用文字与图形共同表达。范围框为示意，不承诺像素级实际命中；精确参数由编译说明提供。

八宫分别突出：乾前方距离、坤周身推开、震普通敌人打断、巽移动路径、坎减速、离灼烧、艮护盾、兑命中回气。未获得技能仍可浏览，标“尚未获得”。不启动试炼或发放经验/奖励。

图形失败保留四步分镜；减少动态效果时不播放动画。切宫、切页、离开窗口/账号时停止播放。静态说明中不显示未来技能或虚构等级锁。

## 输入和可访问性
宫位、节点与符牌沿用方向键，Tab顺序访问全部控件，Enter/空格点击。说明切换后恢复其按钮焦点。Esc先关阵盘确认/出战选择，再回村。触控至少44px；不依赖悬停/拖放。技能键读取玩家改键。首版无手柄控制系统。
