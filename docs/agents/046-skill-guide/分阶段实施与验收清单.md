# 分阶段实施与验收清单

## 接口与数据
- `GET /api/journey`配置新增`skill_guide`、`node_guide`；响应`guide`含已保存效果与八宫参考目录。正式保存仍走原`action=build`。
- `POST /api/journey/build-preview`接收owner_id、revision、nodes、loadout。校验身份/CSRF、修订、冻结、合档与原正式规则，副本编译。返回compiled及guide，不写任何表，不增加修订或结算。
- 前端150ms合并预览；请求序列与账号epoch共同防止迟到覆盖。失败可重试；错误时不使用旧预览冒充新结果。
- `skill_guide.py`只负责说明；实际战斗保持既有执行代码。跨语言契约测试直接调用真实journeySkill，防止两者漂移。
- 不迁移存档；等级、珠ID、出战栏与正式规则保持原格式。挑战显示冻结compiled；编译目录只作参考。
