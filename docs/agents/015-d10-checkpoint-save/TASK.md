# 015 剑碑持久化与刷新恢复

目标：火境剑碑落盘，刷新/重登后可选择按原构筑续关；失败返回洞府保留；成功/明确放弃/完整重开清除旧试炼，祭坛不重复。
用户要求：持续本地开发、测试与交接；不得上传。
范围：可选active_trial存档字段、Python校验、前端序列化/恢复入口/生命周期与测试，均由本Agent负责。
不在范围：新可拆换规则、其他四境、公开竞技防作弊；当前仍客户端可信单机展示。
验收：旧档兼容；非法/递归/未知版本数据拒绝；刷新恢复原构筑和领取标记不新增runs；胜利和清除试炼同一次保存；失败/冲突不宣称已保存；换账号不串试炼；完整重开独立。
依赖：014基线041c697，D06/D10策划及已有revision保存队列。
决定：active_trial版本1独立于旧schema，保存开战构筑原数据而非任意可篡改战斗stats；后端复用现有珠子/出战校验。仅保存剑碑及祭坛离散节点，不保存每帧。旧档字段缺省等价null，不做强制迁移。
