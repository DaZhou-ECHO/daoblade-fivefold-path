# 剑碑存档契约 v1

旧legacy-v1状态新增可选active_trial，缺省或null都表示无可恢复试炼；不提高旧schema_version，不迁移或重置旧角色。

非空记录包含且仅包含：
- version=1；ruleset_id=legacy-v1；rules_version=1。
- id：1至80字符的试炼ID，开战创建，续关保留。
- realm_id=fire；checkpoint_id=swordstone。
- build：仅player/cultivation/loadout，开战复制后深冻结，不含库存、战斗帧、递归active_trial或任意stats。
- claimed_altars：altar-1/altar-2的无重复列表。

后端将build合入标准旧状态，复用既有珠子、路线和loadout校验；珠子须对应当前角色相同槽位、ID、元素、品阶，等级不能高于当前角色。相同试炼ID不能改写build或减少已领祭坛。旧镶嵌不可移动规则保持。

前端用原构筑重新计算冻结CombatSnapshot；恢复满血/剑意于碑，前三敌保持清除，后三敌重置。build不随失败经验成长漂移。存档不保存角色每帧坐标/动作、敌人残血、弹道或随机状态。

离散保存：激活剑碑；激活后领取祭坛；失败沿用旧存档保存；胜利同时写奖励和active_trial=null；明确放弃/完整新开清除旧记录。失败结果的返回洞府保留记录，供洞府按钮继续；退出账号保留该账号记录并销毁旧局引用。恢复/练功不增加正式runs。

存档队列返回成功/失败布尔值。服务器读取或写入失败后，包括游客在内均阻止正式新开/恢复，仍可练功；不自动覆盖冲突窗口。浏览器备份失败不能阻止服务器主存档保存。顶部状态表示服务器结果；激活提示要求确认顶部状态，不声称激活即落盘。

同一会话trial.settled防重复结算；刷新后一次胜利及清除记录在同次SQLite状态写入。账号沿用revision并发保护。游客仍是原有无revision共享槽，客户端可信小型单机展示不等于服务端权威防作弊：手工伪造、游客多窗口竞争、恢复旧数据库的反重放不在本切片，公开竞技需独立任务。

现有014会话文案已由本实现替换；014历史日志不覆盖。未启用可拆换阵盘新规则。
