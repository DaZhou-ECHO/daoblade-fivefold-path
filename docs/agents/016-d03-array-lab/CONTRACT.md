# 阵盘试验 v1 契约与取舍

## 来源与试验边界
D03与专题12已确认A完整八卦图、可拆换、本位限制、独立技能元素。首轮采用离宫候选5节点图：li.core→li.mark→li.focus/li.burst/li.cycle；三个分支互斥。容量3、阶段一、回火需阶段二均是本轮可调整实验值，不是正式境界成长、非古籍规则。其他七宫仅展示方位且标明未开放。

## 单一配置与存档
- static/data/rules/array-lab-v1.json定义节点、边、阶段、容量、样本珠、技能参数；JS/Python分别读取，不修改legacy-v1。
- 存档ruleset_id=array-lab-v1、schema_version=1、rules_version=1、stage=1；beads为固定样本目录，nodes为稳定节点ID到珠子ID或null的映射。
- 未装配的同一ID自然属于试验珠匣；不复制或销毁实例。目录的ID/等级/经验不能被客户端改写。本轮不发经验/战利品，不伪装正式掉落闭环。
- 后端拒绝未知字段/版本/节点、错误元素/功能、重复引用、超容量、未解锁和互斥。允许断开的合法装配，编译结果列出inactive原因；断开核心后技能停用，装回恢复。
- 编译只产生effective/inactive与一个火行技能规格，不求和所有珠子词条，不改变基础面板。

## 两个同珠数方案
- 聚焰：核心＋留痕＋聚焰。技能一（默认Q）范围110、直伤16，3秒每秒灼烧4；不能引爆。
- 引爆：核心＋留痕＋引爆。技能一范围180、直伤12、加1火痕（上限3）；技能二（默认E）消耗命中目标全部火痕，每层14伤害、冷却6秒。
- Q耗12剑意、冷却1.2秒；E耗24。E无可引爆目标不消耗资源。均须在角色朝向和高度范围内命中；不通过全身主元素触发其他旧五行效果。
- 基础劈砍/格挡/剑气维持中性。主要外观阵式、其他宫技能和正式境界/突破留待后续。不是把离宫火色强加给所有技能。
- 试招HUD提供直伤/灼烧/引爆累计，避免木桩回血掩盖两方案区别。开战使用深冻结编译结果；暂停重开保留同一配置，退出回阵盘。

## 独立API与并发
- 独立SQLite表array_lab_saves，使用local/user:id作用域。旧game_saves不迁移、不重排、不写入试验珠；其unique user索引不复用以免冲突。
- GET /api/lab/state返回state/config/compiled/revision/owner_id；未保存时revision=0。
- POST /api/lab/state接收state/revision/owner_id；账号验证CSRF，游客与账号均检查revision。身份变化409，非法状态400，旧revision409；原子写入并返回新revision。
- UI采用编辑→保存中→已保存→可试招；未保存/失败/冲突禁止试招，失败保留草稿，重新读取按钮明确覆盖草稿。账号变化清空旧内存并用epoch忽略迟到响应。
