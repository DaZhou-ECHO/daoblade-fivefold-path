# 016 独立阵盘试验档与离宫组合

目标：实现D03核心首条可玩链：独立测试档→同ID可拆换→离宫本位/连接/容量限制→两种火行方案→冻结配置试招→保存刷新恢复。
用户确认开始落实新配珠玩法，授权本地开发；不得上传。
范围：共享试验规则JSON、JS/Python校验和编译、独立SQLite表/API、主页面阵盘试验面板与隔离试招、双端测试及实际浏览器。由本Agent独立负责。
不在本轮：正式秘境奖励、突破成长、全八宫技能、旧档迁移与正式数值平衡。旧永久档及校验保留。
验收：旧存档不变；同ID/等级/经验拆装；错误元素/功能/重复珠/超容量/未解锁节点拒绝；断开核心技能停用，重装恢复；同珠数两方案在实际战斗中有持续与蓄痕引爆差异；只有保存成功可试招，冲突保留草稿；刷新恢复，账号隔离。
试验决定：采用专题12的5节点图作离宫原型，稳定ID和边，完整八宫方位展示但其他宫未开放。阶段一容量3、回火节点需阶段二（本轮不开放）；均为可调整试验参数，不宣称正式境界成长。基础三招中性，不由外观或试验珠全局加属性。两主动上限内Q留痕、变式E引爆；聚焰方案以短范围持续燃烧取舍。试验珠固定样本，不复制旧珠或发经验/奖励。
