# 019 远距受击后的持续交战
- 目标：修复018真实试玩发现的首领警戒外可被剑气单向消耗问题。
- 用户要求：持续本地优先玩法，暂缓美术，不上传。
- 范围：game.hitEnemy与敌人追击距离；回归和实际试玩；本Agent独立，无并行修改。
- 不在范围：增伤/减血调难度、全关主动拉怪、美术/音效、存档格式。
- 规则：只有实际受伤的敌人进入当局交战；此后在原攻击范围外继续追近，攻击仍须原距离/前摇。未受伤敌人保持原警戒，死亡/新局/续关不继承仇恨。
- 验收：先复现旧版无追击，再修；真实剑气远距命中可引来首领，未受击旁人不连锁拉怪；回归必要检查通过，记录证据边界。
- 依赖：018 fb3ac2e；其中真实胜利明确使用旧警戒漏洞，不当作本修复后胜利证据。
