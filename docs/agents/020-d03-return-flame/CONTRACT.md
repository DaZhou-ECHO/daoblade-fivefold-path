# 回火试验契约

- 依据D03“回火：较低爆发换资源周转”；本轮增加短时护盾作为资源防守取舍，原创原型数值，未称平衡完成。
- `research`沿用`/api/lab/trial`的账号/CSRF/revision事务；无进行中试炼、stage1、至少1胜且12修为，扣12进入研习stage2。重复/旧版本请求拒绝，不再次扣费。普通state保存不能改stage。
- stage2仅开放既有li.cycle，不是人物境界；全局容量仍3，不自动增加技能栏。schema2/rules2追加以前未开放的节点路径，原stage1快照公式与成长不变；不重排或迁移旧永久档。
- 离火核心→留痕→回火，仍与聚焰/引爆互斥。Q基础伤害8（核心每级+2），范围180，留痕最多3；无聚焰燃烧/引爆伤害。
- E只取前方范围内活敌火痕并清零，单次全部目标合计最多回24剑意、9护盾，冷却6秒，无剑意成本，无伤害。无痕不回资源、不起冷却；背后/死亡目标不计。
- 盾持续3秒，刷新取较大盾值，不加法叠盾；到期清除。回火珠每级增加每痕护盾和单次护盾上限各1，三级上限11；剑意上限不随等级扩大。
- 开战仍冻结build和有效珠，试招不成长；真实胜利只给有效回火珠经验。研究解锁本身不加珠等级、不重置珠ID/XP。
- 研究丢失ACK时重新读取；禁止盲目重复扣费。取消/失败事务不改变余额和阶段。
