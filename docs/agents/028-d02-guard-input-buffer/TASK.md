# 028 初次普通格挡短缓冲
- 目标：K在收招/受击/施法/闪避尾部按下且仍持有时，0.18秒窗口内恢复到普通防守；避免首次拒绝后长按无响应。
- 要求：本地开发、玩法优先、交接完整、不上传；本Agent独立。
- 范围：beginBlock与短窗口、释放/暂停/攻击/新受击取消、回归、D02规则与实玩。
- 不在范围：扩大取消窗口、缩短硬直、自动弹反、无限等待、伤害或美术变更。
- 验收：不能行动时不提前举盾；窗口内可行动且仍持有才普通挡；过期/释放/清理/新攻击或受击取消；第三段劈砍未结束不被取消；立即可格挡时原弹反窗口保留。
- 依赖：027 ca0c240；明确更新026的“受击中首次K不缓冲”局部选择，以本任务D02补充为准，不改前任交接。
