# 025 格挡与击退来源方向
- 目标：实际敌人/投射物命中使用中心来源点，格挡和击退统一相对玩家中心；修复贴身/宽体敌人方向误判。
- 依据：024实测方位提示右侧，但贴身格挡仍按敌人左边缘判向；不是提高防守数值的平衡调整。
- 范围：两处近战/一处敌投射物来源点、damagePlayer击退基准、回归和真实防守；本Agent独立，仅本地不上传，不扩美术。
- 不在范围：攻击范围/伤害/前摇/无敌时长/盾数值调整、自动防守、属性克制、新敌人。
- 验收：实际火境与通用敌人攻击中，中心在前则普通挡/弹反有效，中心在后不被挡；无盾受伤向远离中心来源方向击退；投射物一致。先写失败回归证明原问题。
- 基线：024 470dca3。024交接提到三处近战经实际核对为两处近战加一处投射物，按真实代码修。
