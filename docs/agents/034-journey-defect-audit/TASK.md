# 034 玩法缺陷排查与窄屏操作

## 目标与用户要求
继续本地开发，尽力发现并消除缺陷；不承诺无法证明的零缺陷。仍不上传、不做美术。
## 修改范围
基于fcf644f，检查正式征程编辑未保存状态、异步/换号边界、窄屏战斗与触屏按钮可达性；发现实际缺陷再修代码及相关测试，记录可复现证据。
## 不在本任务内
联网反作弊、所有实体设备的适配承诺、美术音效扩展、无限玩法与远端操作。
## 验收条件
构筑编辑不会因切宫/保存另一部分/读档状态渲染而静默丢失；未保存内容不能被误当成出战构筑。375宽竖屏、667宽横屏的所有战斗按钮可见可达；浏览器普通输入验证必要主流程，模拟视口不冒充真实手机。必要回归与开发日志、完整交接落盘。
## 依赖与归属
依赖033已完成的十图/正式成长主流程；单Agent负责journey-ui.js、相关模板/CSS/测试及本任务文档。保护既有试玩库，不覆写旧Agent记录。

## 实际收尾范围
进一步修复暂停按钮误恢复和换号期间旧保存/恢复回调干扰；提交前拦截首次读档失败不能重试的本轮新增风险。窄屏布局使用游戏区剩余高度分配画布；模拟四视口实测，非真实手机/多指。屏幕按钮实际到碑、刷新恢复、首领战败续关；不冒称屏幕按钮整局胜利。
