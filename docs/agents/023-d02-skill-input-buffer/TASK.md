# 023 Q/E短输入缓冲
- 目标：挥剑/施法/受击/闪避即将结束或技能冷却快好时，提前按Q/E仍能在180ms窗口内实际施放一次。
- 用户授权：持续本地玩法开发，不上传，暂缓美术。022实际试玩暴露动作衔接吞技能输入。
- 范围：game输入请求/帧更新/清理、真实战斗回归与试玩，本Agent独立，无并行工作。
- 规则：仅一个待施放槽，最新Q/E覆盖；不自动连发。后续J/L/格挡/闪避取消技能请求；跳跃/方向不取消。窗口到期丢弃。施放时重新校验冷却/剑意/构筑/目标/朝向。阻塞在180ms外不能等很久后自动出招。
- 清理：暂停/死亡/退出/销毁/新受伤/服务等待清掉；格挡中不缓存技能。
- 不在范围：动作取消窗口扩大、自动瞄准/自动格挡、伤害/数值调整、美术、存档格式。
- 验收：短收招能施放一次，长阻塞失效，Q/E覆盖与J防守优先、不提前扣费、重验资源/目标、暂停/伤害/销毁无幽灵施法，键盘触屏同一入口。
- 基线：022 3259b41，旧五境/阵盘和独立存档保持。
