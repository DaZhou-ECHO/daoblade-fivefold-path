# 014 火境会话内剑碑续关

目标：D06火境清除前3敌后，在x1640地面剑碑激活，恢复气血/剑意一次；死亡可续关。
用户要求：持续本地迭代、记录交接；不上传。
范围：火境定义、游戏生命周期、结算按钮、回归测试；本Agent独立负责。
不在本切片：刷新恢复（后续D10）、其他四境检查点、数值重平衡和新构筑系统。
验收：未清场/空中/远离不可激活；仅激活一次；续关冻结原始构筑、保留已领祭坛，前三敌不复活、后三敌重置；续关不计新闯关，完整重开另计；胜利至多一次，无检查点/胜利不可续。
依赖：013 ba82f57，012稳定位置与敌人ID。
取舍：剑碑x1640在火焰区与敌人出生点之外。死亡仍沿用旧5经验；续关奖励快照不随经验改变。会话结束丢弃进度必须如实提示，后续持久化完成后再替换文案。
