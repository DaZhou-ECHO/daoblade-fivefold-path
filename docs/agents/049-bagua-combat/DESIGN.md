# 八宫合剑谱实现约定

## 文化取材

- 《易传·说卦》方位与卦性：https://zh.wikisource.org/zh-hans/周易/說卦 。采用后天方位，南上北下。
- 《周易·贲》离下艮上：https://zh.wikisource.org/zh-hans/周易/賁 。配方主宫为下卦、副宫为上卦。招名与动作属于本作原创。
- 《蜀山剑侠传》第一八七回：https://zh.wikisource.org/zh-hans/蜀山劍俠傳/187 。取飞剑收放、护持与变招的表现思路。
- 《庄子·养生主》：https://zh.wikisource.org/zh/莊子/養生主 。取观察空隙与出手节奏的表现思路。

## 规则与参数

- 单一目录：static/data/sword-combos.json，服务端编译配置和UI共用，八配方各宫恰为一次主、一次副。
- 顺序：两主动栏前者主宫、后者副宫；两核心均连通才编译combo。心法、现有40珠、1—3级和容量规则保留。
- 起式：主宫直击命中，艮须其本次盾吸收敌方伤害；巽须实际跨过敌人。持续伤害不触发。
- 接招：1秒战斗时间，新按副宫键才能接；在命中到起式收势之间按下可缓冲，早按不转为合招。副宫一次资源扣费与冷却，合招不递归起式。
- 直击预算：按副宫编译伤害及离心法；每个目标每次合招最多结算一次。分灯有次目标时主60%/次40%，孤立目标100%。护盾12/3秒、回气最多8一次，灼烧与首领控制抗性沿既有规则。
- 合招细节：回震0.65秒向前180再向后180；退步140、风痕0.4秒；回锋按实际穿行段；候潮0.75秒，60%时合拢，横宽100；归剑0.35秒沿命中点到接招站位回线；分灯仅追同高度后方240内最近目标。
- 新版普通宫技起手0.12秒，动作0.34秒。击中时开窗，画面姿态与伤害同时序。
- 挑剑0.4秒，0.08—0.23秒生效，前上方75×130，伤害基础攻击×1.12并计师门；轻敌离地期间最多挑起一次，首领/重敌不挑起。
- 坠剑伤害基础攻击×1.2并计师门，剑身和落地共用目标集合，落地收势0.22秒。暂停取消后不得转成普通劈砍。
- 蓄剑：L松键出剑，满蓄0.45秒；普通耗20，满蓄耗28、直击×1.4、最多命中两敌；蓄势移动速度减半。按键采用当前改绑映射。
- 格挡/闪避/受创/暂停/失焦/死亡清理待接与蓄势；环境伤害不启动承击合招。

## 演武与兼容

- /api/journey/practice-preview延用save_id、账号、CSRF、revision和冻结校验。草稿预览校验真实珠/容量；recipe_id借用对应两颗一级核心，仅返回临时编译。
- 演武共用BattleGame和剑术执行器，独立canvas和生命周期。禁止创建正式trial及调用奖励、剑碑、任务事务。复位/退出销毁该局，保存和草稿由原控制器管理。
- 新挑战map_version2/combat_version3；显式接受1/1、2/2、2/3。进行中老局不重编译，剑碑恢复不携带临时蓄力和接招窗。
- 角色美术读取sword_pose/charging，保持绘制与碰撞数据分别负责。
