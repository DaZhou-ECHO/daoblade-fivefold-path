# 山河问仙：世界与首章执行设定

本文件是048正式工作设定，游戏中已实现的内容以TASK、交接与验证记录为准。未来地区只作为创作边界，不代表可玩内容。

## 世界命题

修行者借山河之气求仙；当求仙消耗了普通人的生活，持剑者应如何选择？成仙既是突破生命局限的愿望，也是必须承担后果的实践。

- 人间：村落、河流、药圃、商道、矿岭、旧宗门。普通人的生计决定玩家为何出发。
- 洞天：依附具体山川、内部环境异于外界的天地；不把所有洞天写成更高级的空洞战斗场。
- 天外：古人留下记录、当代尚不能完整解释的仙途。首章不公开完整答案。
- 五行：灵气的变化与招式理解方式，保留现有固定珠规则；不是世界只能存在的五种地区。
- 八卦：剑修理解、联通变化的图式。本命剑与阵盘装配是原创游戏规则，不宣称来自古籍。

## 历史与势力

古代镇脉网络原为疏导地气、护佑聚落。后世部分修行者将其改为登霄之路，以灵气维持封闭洞天并尝试重新开启仙途。网络失衡，引发逆脉：逆流、错季林木、不熄炉火、守境者失控。

- 守脉人：保护聚落、修补旧阵；对是否关闭仙途存在分歧。
- 登霄会：掌握旧阵资料，认为集中灵气可维持洞天、避免更大灾害；其代价正在落到山下居民身上。
- 山泽灵属：有伤人的妖物，也有同受逆脉之害的异类。后续可以出现敌对、协助与共居关系。

首章不把所有妖怪归为同一势力，也不为叙事改写既有首领技能或名称。

## 人物与动机

主角是村中修剑学徒。本命剑与旧剑碑共鸣，使其能识别旧阵痕迹；这来自可学习的传承，不以仙帝转世解释一切。村井失水与药队失联促使其出行。熟识的人在药队中，具体往事在后续章节展开。

师父留村维持防护、教授技艺，等待五地记录后共同复核旧阵。商人面对真实的货源与道路问题。悬赏来自居民委托，不是无来源的任务面板。

## 第一章：逆脉妖潮

1. 行旅簿开场：井水失流，药队未归，接下调查。
2. 五地均可探索，火境作为起始构筑适合的推荐，而非剧情锁。
3. 每地任选一条现有路线胜利即解锁该地调查记述；另一条提供不同路途说明及可重访支路。
4. 玩家主动阅读五条线索。历史通关满足调查事实，但不伪造已读。
5. 回村复核：镇脉恢复疏导用途，井水复流；失联者留下的剑讯指向图外洞天。
6. 本章结束不自动筑基，不新增最终关卡，不重复补发既有首通奖励。

实际地区、线路说明、线索及结尾的共享数据源为`static/data/shanhe-world.json`。剧情没有数值分支选择；后续选择系统须独立立项。

## 村落与任务

- 西：山河图与传送点。中：悬赏栏、村井与居民生活。东：演武坪、独立剑台、剑坊。
- 主线、村民委托、悬赏分别显示；日志可随时查看，挑战中村落事务冻结。
- 初期村民委托为拜访师父、查看剑台、询问商人，无额外数值奖励。
- 悬赏每地区清剿/支路调查各一项模板，一次一项，无每日门槛。接取后开局快照；同地区胜利才完成，支路须同一局取得祭坛奖励。每项2修为，回村领取，流水去重。
- 失败不完成任务，可以再出发；有进行中挑战时不得更换任务。完成后先领取，不允许取消丢失奖励。
- 井水与灯火由章节结案驱动；药架由木地调查已读驱动；货物由商人委托完成驱动。装饰无碰撞。

## 长期地图创作边界

- 镜湖城：水城生活与倒影路途。
- 行舟墟：船只交通、漂移岛屿与潮汐。
- 悬岳古道：栈道、升降楼与纵向山门。
- 无昼洞天：遗迹状态改变，过去与现在互证。

本期均不提供进入按钮或虚构完成度；未来另立地图版本与旧局兼容方案。
