# 045 剑心环阵与登录优先开场

- 目标：用中心本命剑及八方光路展示现有八宫构筑；每次启动先显示行旅入口，玩家明确选择已登录角色、登录/注册或游客继续后进入新手村。
- 用户要求：图形化珠槽与连线、五节点及四符牌、草稿与服务端生效分明；桌面/手机与键盘/触控可用；既有账号和游客各自保持单一正式征程，游客可导入无进度账号。
- 修改范围：行旅入口与村落显示接线、师门阵盘模板/样式/前端交互、必要的账号与正式档读取接线、定向测试、README/CHANGELOG未发布项及045证据。
- 不在本任务：五行数值、珠子与容量规则、服务端构筑编译、十图地形及战斗、每账号多角色存档、游客数据覆盖已有账号。
- 验收：开场已登录/未登录/游客、账号切换、导入和读取失败；环阵方位与珠槽状态、互斥/断联/容量、四符牌、冻结/冲突及保存生效；桌面/窄屏、键盘/触控与进图回村。运行完整项目、资源、语法检查和浏览器核对。
- 前置依赖：044功能`006a541`及交接`d5791b2`；044实体触控与完整人工通关仍待验收。
- 并行参与者：无。
