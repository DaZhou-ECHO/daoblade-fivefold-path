## 1. 已确定的设计方向

根据团队主管理员在方案讨论中的选择，本版本遵循以下方向：

1. 战斗采用灵活剑术节奏，保留三段连击，增加短闪避。
2. 闪避和格挡同时存在：闪避负责换位与躲避，格挡负责正面防守和反击。
3. 优先强化五行特色，使不同修行真正改变劈砍、格挡和剑气。
4. 全身共用主副五行：主属性决定招式形态，副属性提供补充效果，八卦决定强化方向。
5. 五种主属性先形成明确打法：金穿透、木续航、水控制、火爆发、土守御。
6. 灵珠正式镶嵌后不能取下、替换或移动；品质决定初始词条起点，低品质灵珠也能够持续成长。

版本目标：玩家使用同一套基础按键，通过长期修行形成可感知、可理解的不同剑术流派。

## 2. 当前基础与开发前核对项

现有项目已经具备 Canvas 横版战斗、三段劈砍、格挡与完美格挡、剑气、五行秘境、灵珠成长、八卦修行以及 SQLite 存档等原型基础。火属性秘境已经有近战剑卒、突进刀客、术士和首领的专属表现。

上一轮代码阅读发现以下需要优先核对和修正的项目；它们属于代码层面的分析结论，开发时仍需建立复现步骤并验证：

| 核对项 | 当前风险 | 目标行为 |
|---|---|---|
| 冷却期间输入 | 下一剑可能被直接忽略 | 允许短暂缓存一次有效后续输入 |
| 动作互斥 | 劈砍、格挡、剑气可能重叠 | 明确动作状态、衔接和取消时机 |
| 近战命中区域 | 部分攻击只依据水平距离 | 同时检查高度、朝向和实际攻击范围 |
| 穿透剑气 | 可能多帧重复命中同一个敌人 | 每个投射物记录已命中对象，次数符合技能定义 |
| 暂停与焦点 | 切换页面、窗口后可能残留输入 | 暂停时清空按键，恢复后无突然位移或补算伤害 |
| 五行并列 | 界面显示“未定”但内部采用固定排序 | 显示、规则计算和实际战斗效果一致 |

旧版测试结果见 `docs/测试报告.md`。旧版通过结果不能代替本版本的验收结果。

## 3. 基础操作方案

| 操作 | 默认按键 | 用途 |
|---|---|---|
| 左右移动 | A / D | 调整距离、朝向和站位 |
| 跳跃 | Space，兼容 W | 越过地面攻击和平台 |
| 三段劈砍 | J | 近战输出、积累剑意 |
| 普通格挡 | 按住 K | 正面减伤，移动速度降低 |
| 完美格挡 | 受击前按下 K | 化解攻击、创造反击机会 |
| 剑气 | L | 消耗剑意，处理远处目标 |
| 短闪避 | Shift | 快速换位，短暂躲避伤害 |
| 道法 | Q | 使用八卦路线解锁的特殊能力 |
| 暂停 | Esc | 继续、重试、设置和退出 |

提供基础按键修改与恢复默认设置；同一动作不因五行改变而更换按键。当前阶段以键盘体验为主要验收对象。

### 3.1 移动与跳跃

- 转向和起停应清晰，减少非预期的滑行。
- 增加短暂的跳跃输入缓存和离开平台边缘后的跳跃宽容。
- 地面、平台和落地坐标保持一致，受击与闪避不应造成卡地或穿越边界。
- 二段跳继续作为修行强化，基础跳跃本身开局即可可靠使用。

### 3.2 连击与动作衔接

- 三剑具有不同的动作和打击节奏，第三剑具备更高收益和更明显的收招风险。
- 在允许的衔接窗口内，提前按下一剑可以被缓存；只缓存有限输入，避免排队执行大量攻击。
- 明确前摇、生效、收招和取消窗口，避免角色同时攻击与格挡。
- 建议前两剑在收招后段允许衔接格挡或闪避；第三剑不能任意时刻取消。
- 命中反馈加入短暂顿帧、受击动作、音效与可关闭的轻微震屏。
- 特效轮廓应与命中范围接近，不能出现明显的“看起来打中但无效”。

### 3.3 格挡、反击与闪避

- 普通格挡仅防御正面攻击并减少伤害，不提供持续无敌。
- 完美格挡创造短暂反击窗口，由玩家随后按 J 发动反击。
- 连续快速点按不能无限刷新完美格挡机会。
- 短闪避使用冷却控制，不消耗剑意，保证剑意耗尽后仍有基础防御手段。
- 闪避的位移距离、无敌时段和冷却须通过试玩确定，不能连续维持无敌。
- 基础移动、单跳、劈砍、格挡、剑气和短闪避开局可用；八卦负责强化这些动作。

所有时间窗口、伤害和恢复量均为待调参数，本文不将其锁定为最终数值。

## 4. 战斗资源循环

本版本保留生命与剑意两种主要资源。

```mermaid
flowchart LR
    A[劈砍命中] --> B[积累剑意]
    C[完美格挡] --> B
    C --> D[敌人露出破绽]
    D --> A
    B --> E[释放异化剑气]
    E --> F[控制距离或制造输出机会]
    F --> A
```

- 劈砍有效命中恢复少量剑意，鼓励主动近战。
- 完美格挡提供剑意收益和反击机会。
- 剑气消耗剑意，承担远程、控制或爆发功能。
- 普通格挡提供容错，闪避提供换位能力。
- 本轮不新增道心条、架势条或多套消耗资源。

## 5. 主五行的十五项基础异化

以下效果为计划中的玩法目标，不代表当前已经全部实现。

| 主属性 | 劈砍 | 完美格挡 | 剑气 |
|---|---|---|---|
| 金：穿透 | 第三剑向前延伸，强化直线攻击 | 产生短距离反震剑芒 | 穿透多个敌人 |
| 木：续航 | 命中积累灵种，第三剑收获少量生命 | 获得限量恢复效果 | 命中种下灵种，与近战衔接 |
| 水：控制 | 连击积累寒意，第三剑造成明显减速 | 短暂减缓攻击者动作 | 形成减速水刃 |
| 火：爆发 | 第三剑引爆目标身上的燃烧 | 下一次劈砍获得短暂烈焰强化 | 命中后造成小范围爆炸 |
| 土：守御 | 第三剑产生击退震波 | 获得短暂护盾 | 速度较慢、更加厚重，击退能力强 |

### 5.1 平衡边界

- 木的恢复设置触发间隔或上限，不能因范围命中、穿透或重复判定无限回血。
- 水对首领的控制具有强度和持续时间限制，不能永久锁定首领。
- 火的爆炸具有范围与触发频率边界，避免同一次攻击无限连锁。
- 土的护盾和减伤具有上限，不能长时间无伤站桩。
- 金的穿透依赖可靠命中记录，不能对同一敌人无意重复计算伤害。
- 进化带来的强度增长需要边界，不能使攻击范围、控制或防御无限扩大。

## 6. 副五行、八卦与词条的分工

统一采用以下组合关系：

```text
主五行 → 决定三种基础招式的核心形态
副五行 → 提供一个简洁的补充效果
八卦   → 决定玩家更擅长哪种操作
词条   → 调整触发条件、范围或数值
```

### 6.1 副属性效果方向

| 副属性 | 补充方向 |
|---|---|
| 金 | 增加有限的穿透机会或有效攻击距离 |
| 木 | 达成特定命中条件后恢复少量生命 |
| 水 | 提高剑意获取或附加轻度减速 |
| 火 | 附加少量燃烧 |
| 土 | 提高击退或提供小额护盾 |

同一效果不因不同来源而无上限叠加。副属性采用可组合机制，暂不为所有双属性组合分别制作独立技能套装。

### 6.2 八卦专长

| 卦象 | 强化方向 |
|---|---|
| 乾 | 攻势、剑气与正面输出 |
| 巽 | 身法、移动与空中操作 |
| 坎 | 剑意、减速与控制 |
| 艮 | 格挡、反击与护盾 |
| 坤 | 生命、防御与守御 |
| 震 | 击退、硬直与破势 |
| 离 | 暴击、燃烧与爆发 |
| 兑 | 恢复与持续作战 |

八卦路线不强制绑定某一种五行。两个同为火主属性的玩家，可以分别形成偏剑气、偏连击或偏反击的构筑。

### 6.3 组合示例

- 主火、副金、偏乾卦：第三剑引爆燃烧；剑气爆炸后仍可继续贯穿；乾卦强化剑气能力。
- 主土、副木、偏艮卦：格挡反击后获得护盾；有效反击带来少量恢复；艮卦强化防御反击。

基础技能应稳定可理解，随机词条创造构筑差异，不随机改变按键的基本含义。

## 7. 永久修行与预览

正式镶嵌不可撤回，需要用充分的信息帮助玩家做决定：

1. 镶嵌前显示五行数值和主副属性的前后变化。
2. 展示本次对劈砍、格挡和剑气的具体影响。
3. 明确标出即将开启的卦位效果。
4. 提供练功场临时试用，试用不写入正式镶嵌、珠匣、进度或奖励。
5. 主副属性可随后续修行变化，已经获得的八卦能力继续保留。
6. 主副并列规则在开发时统一确定，确保前端预览、后端规则和实际战斗一致。
7. 品质保持不同初始等级与词条起点；低品质可以成长，核心玩法不只对高品质灵珠开放。

“无法撤回”针对正式镶珠决定，不代表玩家的主副五行从此永远固定。

## 8. 熔岩天宫验证关卡

本版本在同一火属性秘境内验证五种主属性，控制关卡差异对测试的干扰。

| 敌人 | 验证目标 |
|---|---|
| 熔岩剑卒 | 三段连击、普通格挡与反击 |
| 赤焰刀客 | 蓄力预警、短闪避与换位 |
| 火羽术士 | 剑气、远程威胁处理与站位 |
| 离火剑魁 | 基础动作与五行效果的组合使用 |

敌人规则优化要求：

- 蓄力、出招和收招具有清晰表现。
- 在适当时机锁定出招朝向，避免突进过程中持续追踪并突然转向玩家。
- 普通斩击、突进和地面剑波具有不同姿态与轮廓，不只依靠颜色识别。
- 根据攻击类型使用正确的高度和范围判定。
- 保持近战为主，协调多个敌人的出招节奏，避免无提示的同时围攻。
- 受击、被格挡、破绽和死亡都应有可辨认反馈。

## 9. 三阶段开发与验收

### 阶段 A：基础操控

交付内容：输入缓存、动作衔接、短闪避、可靠命中、暂停与快速重试、基础输入设置。

验收条件：

- [ ] 提前按下一剑能在合法窗口内接上，过早或过期输入不会无限排队。
- [ ] 攻击、格挡、闪避和受击之间没有非预期同时生效。
- [ ] 跳跃能够正确躲过应当可以越过的地面攻击。
- [ ] 穿透投射物不会无意重复命中同一个敌人。
- [ ] 暂停、切换窗口、恢复和重新挑战后按键状态正常。
- [ ] 攻击范围、角色位置和画面反馈一致。

### 阶段 B：五行剑术

交付内容：五种主属性的三招异化、简洁副属性效果和八卦强化衔接。

验收条件：

- [ ] 五种主属性在同一场景中具有不同的战斗作用。
- [ ] 主副属性、八卦和词条能够按统一规则组合。
- [ ] 木恢复、水控制、土护盾、金穿透和火爆炸符合叠加上限。
- [ ] 无主属性和属性并列时，显示与实际效果一致。
- [ ] 基本动作不依赖高品质灵珠才能正常使用。

### 阶段 C：修行验证

交付内容：镶嵌预览、练功场、火关平衡和旧存档兼容。

验收条件：

- [ ] 镶嵌预览准确描述属性、三招和卦位变化。
- [ ] 练功场试用不会修改正式角色数据。
- [ ] 正式镶嵌仍不能取下、替换或移动。
- [ ] 旧存档的灵珠编号、品质、等级、经验和镶嵌位置得到保留。
- [ ] 五种主属性分别完成火关测试，记录问题与平衡结论。
- [ ] 主副属性变化后，已经解锁的八卦能力保持有效。

版本体验验收标准：玩家不只通过颜色，也能通过实际用途感受到五行区别；每次受伤能够理解原因；每次永久镶嵌前能够理解后果。
