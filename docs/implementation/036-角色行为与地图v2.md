## 已实现
| 子系统 | 实现与边界 |
|---|---|
| 集中动作策略 | combat-controller.js提供阶段、动作许可/拒绝原因、有限输入队列与优先级；实体仍唯一拥有时钟，ActionState只读 |
| 输入 | 新正式局按闪避→格挡→技能→剑气→普攻仲裁；Q/E共用一个等待槽，执行才扣气，暂停/失焦/错误/销毁清理 |
| 衔接 | 第一二剑有效段不可取消，收招可转防守/闪避，第三剑完整收招；起手锁朝向，下一剑可转向 |
| 移动 | 140ms跳跃缓冲/110ms离台宽容保留；松键截断上升速度形成小跳，长按最大跳高保留；地面/空中加速分离 |
| 碰撞 | 地面/实体/单向平台/装饰区分；下＋跳穿过当前单向平台；高速横移扫过薄墙不会穿透 |
| 防守 | 普通挡命中耗12剑意、重击20；挡时不自然回气，离挡延迟0.3s；不足破防0.45s，本次按未挡伤害；精准格挡沿用原窗口/回气；环境机关不可挡 |
| 表现 | 普通挡扣气、精准格挡和破防独立HUD/事件提示；phase来自同一动作进度，不用动画反向决定命中 |
| 分段地图 | 五境各ridge/hollow共10张v2灰盒；7个段落、地标、实体低掩体、单向平台、两条奖励支路、可开启回环栈桥、稳定出口 |
| 遭遇 | enemy-1/2/3/4/6必做，enemy-5为可选上层守卫；不全清自动结束；入口按段落激活，首领场镜头约束 |
| 地形接入 | 敌人低台阶/上层守卫活动边界；投射物受实体阻挡；巽位移不能穿过实体 |
| 胜利 | 必做遭遇和首领完成后开放出口，F或触屏交互确认，后端再校验required_ids和exit_id |
| 版本与存档 | 新正式试炼冻结combat_version=2/map_version=2；旧局缺字段按1，继续旧地图/旧动作；未知/不匹配版本明确拒绝，不改写坐标 |
| 检查点 | 剑碑保存粗粒度状态，保持原构筑、已领祭坛和捷径；后段敌人按原规则重置，回执仍防重复发奖 |

两类地图区分上行与右登左返，五境在危险节奏、低掩体位置/宽度、附加观察台、遭遇位置与地标上有差异。它们仍是灰盒，不是十套全新剧情或最终美术。

## 最小接口
- 页面注入static/data/journey-maps-v2.json，同一JSON供Python和JS读取，不双写敌人ID/出口定义。
- DaoBladeController：config/phase/permit/enqueue/consume/physics/drop。permit返回status与reason。
- LevelDefinition v2：sections、platforms[].collision、required_ids、shortcuts、exit、landmarks；getJourneyDefinition(realm,map,version)，默认1保持旧调用。
- POST /api/journey新增action=shortcut，字段trial_id/shortcut_id/revision/owner_id；普通v2胜利还需exit_id="exit"。合法标识从该局地图配置取得，账号/CSRF/版本/事务逻辑沿用。
- active_trial新增combat_version、map_version、opened_shortcuts。breakthrough仍冻结v2战斗，但使用旧独立首领场与原突破结算，不要求普通出口。
- BattleEvent新增player_guard_broken、action_cancelled和可选guard_cost；声音消费者不认识新事件时安全忽略。
- 客户端仍报告战果，不是服务器权威物理或防作弊。

## 默认操作
A/D移动，Space/W跳跃；短按小跳/长按高跳；S＋跳跃单向平台下落；F交互/开启捷径/确认离境。J三连、K防守、L剑气、Q/E主动、Shift闪避、Esc暂停保持。S/F可重绑定，触屏增加下/交互按钮；旧键位配置自动补齐默认项。

## 尚需验收与调优
1. 真人完整通关与8–12分钟时长未证实；不靠拉长空地凑时长。自动输入通关不代表手感平衡完成。
2. 当前仅灰盒、现有角色资源与简易标识；专用国风场景、完整新动作帧、配套音效不在本轮新增。
3. 后续修改v2平台/锚点不能静默覆盖活跃旧局，应新增地图版本并保留读取器。
4. 本轮远端Git连接失败，编号需上传前再次协调；没有自动推送、PR或合并。
5. 所有GUI失败尝试与实际限制如实记录，不把引擎胜利写成浏览器胜利。
