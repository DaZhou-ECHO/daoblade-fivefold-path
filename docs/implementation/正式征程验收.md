## 启动与接手入口

- 代码在本地work/033-journey-usability-local；不上传。
- `.venv/Scripts/python.exe -m flask --app app run --no-reload --port 5064`；测试实例设置DAOBLADE_DATABASE为绝对路径work/u16-array-lab.sqlite3。当前服务已运行，勿再占同端口。

- 每宫选节点的对应珠，在2主动/2心法下拉栏选择后，点击“保存全部改动”一次提交全盘及出战栏。跨宫草稿保留；未保存时禁止开战，放弃草稿可还原。保存中、冲突或挑战中会锁相关控件；读回服务确认后才出战。当前境界及已装/容量始终显示。
- 主路连续地面，A/D、空格单跳、J劈砍/K防守/L剑气、Q/E本宫技能。选高径或回廊后开战冻结地图；支路导航显示方位/距离/高度/补给与修为，沿台阶进入即可自动领取；两端均可落回主路。
