## 有限首版规则

- 八宫后天方位与本位：震/巽木、离火、坤/艮土、兑/乾金、坎水。每宫核心→纹路→锐式或流式（互斥）；核心→心法。珠实例宫位专属且本位元素，稳定ID，拆下不改等级/经验。
- 容量练气6、筑基10，全部已装节点占容量（含断线），不用境界命名装饰研究阶段。研习stage2仅旧试验档，与正式境界无关。
- 2主动槽Q/E，2心法槽；可选任何有效宫，重复宫禁止。只有已选择的连通技能链/心法参与战斗与XP；全身J/K/L中性。有效核心即可主动；心法需核心+心法珠。拆核心保留失效选择并就地提示，不暗中切技能。
- 主动：乾直线远击，兑击敌回气，震近距震荡延后非首领攻击，巽沿地面短冲斩，离直伤/灼烧，坎减速，艮短护盾+近击，坤范围推开。纹路提高效力，锐式增伤增耗，流式减伤减耗；不同宫共用有限强度预算。
- 心法（仅入选两项）：乾攻击+2、兑回气+1/秒、震僵直系数+0.15、巽速度+12、离技能伤害+2、坎冷却×0.9、艮防御+2、坤生命+15；单宫一份不重复，未出战宫不叠加。
- 初始赠离核心/纹路/锐式、艮核心/心法，默认离Q、艮心法。其余由挑战获得，不能用全目录测试珠冒充掉落。
- 普通胜利12修为；元素首次通关给本元素所有宫的核心/纹路/心法（已有转经验）；后续每胜按目录依次给一个未拥有的变式，拿齐后固定轮转重复。重复同实例+5XP，满级转2修为；不新建同ID珠。出战有效快照每珠胜利20XP，上限3级/20XP升级；备用与本场新掉落不领出战XP。
- 筑基需24修为并通过独立短挑战（一个正式火境首领，无小怪）；成功消费24扩容到10，失败不扣不发奖，可重试；不需集齐元素、不毁珠。突破不发普通掉落/胜利XP。
- 支路祭坛即时回复12血18气，一次性领取在服务器ACK后；通关每处已领支路另给4修为。失败/续关不重复；两地图都固定祭坛ID，开战冻结map_id。
- 首版客户端报告战果，事务+revision+回执防重放，不能宣称服务端反作弊；不做排行榜/交易。
