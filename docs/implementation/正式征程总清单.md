## 已收敛首版规则

1. 采用完整A结构：后天方位，上南下北左东右西，中间剑心；震/巽木、离火、坤/艮土、兑/乾金、坎水。每宫核心→纹路→锐式或流式（互斥）；核心→心法，共40节点。原创游戏机制，不称古籍法术。
2. 珠实例宫位专属且本位元素/功能匹配，稳定ID。拆下不改变等级/经验；不共享同一实例。已装节点全占容量，断线时明确停效。初始离核心/纹路/锐式、艮核心/心法5赠珠；其余通过战斗掉落。
3. 练气容量6，筑基容量10，首版到筑基为止。至少24可用修为，独立火首领心劫成功后才扣24；失败可重试、不扣、不毁珠、不发普通奖励。旧试验档“回火研习stage2”与正式rank无关。
4. 保持2主动Q/E、2心法，同类栏不能重复同宫。只编译被选且连通的链；同核心同时支持主动/心法只发一次经验。J/K/L保持中性，不把所有已装宫全局叠加。外观未扩展。
5. 主动：乾远距直线击；兑命中回8剑意，每次施法一次；震近震/打断杂兵、首领不硬控；巽短冲180贯斩；离直伤/3秒灼烧每秒4；坎杂兵减速2秒/首领0.8秒；艮12护盾3秒+近击；坤周身击退70/首领15。
6. 核心基础18伤，每级+2；033补齐非核心三级收益：纹路加4/5/6伤，锐式加6/8/10伤、耗16；流式减伤3/2/1、耗8/7/6；基础耗12、CD1.5秒，乾射程300、坎220、其余170。心法三级：乾攻击2/3/4，兑回气1/1.5/2，震劈砍击退10/14/18（首领2/3/4），巽速度12/16/20，离直伤2/3/4，坎冷却倍率0.9/0.85/0.8，艮防御2/3/4，坤生命15/20/25。旧进行中冻结快照缺少等级字段时按1级保持原效果，不擅自重编。
7. 普通胜利12修为；每处已领祭坛再+4。元素首通必得对应宫全部核心/纹路/心法；后续每胜按目录给一个未拥有变式，拿齐后按该境通关次数轮转重复。重复同ID+5珠经验，已满级转2修为，绝不复制实例。
