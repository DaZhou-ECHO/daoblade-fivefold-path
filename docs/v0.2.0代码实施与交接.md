## 实际验证

在 PowerShell 的项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --check static/js/game.js
node --test tests/combat.test.cjs
```

结果：Python 20 项通过、JavaScript 战斗逻辑 8 项通过、语法检查通过，零失败。首次在受限测试沙箱内运行时，pytest 默认临时目录不可写，出现 4 个环境权限错误；改用可写临时目录后 20 项通过，随后在正常项目环境中执行上述标准命令也为 20 项通过。

另以 `python -m flask --app app run --no-reload --port 5055` 启动开发服务器，`GET /api/health` 返回 `status: ok`。浏览器手动检查了熔岩天宫入场、角色地面站位、暂停菜单、按键设置、练功场入场与退出。浏览器测试时一次正式关卡因角色死亡自动结算，随后已撤销本次产生的闯关计数；未给正式存档写入灵珠或镶嵌。

自动测试覆盖：五行并列规则、旧存档字段与卦位保留、非法词条、输入缓冲、完美格挡后的主动反击、闪避与跳跃、剑气单目标去重、五种主属性核心效果、试用构筑隔离、火关突进方向锁定。

## 待人工验收与限制

- 尚未用五种正式构筑分别完整通关火属性秘境。敌人的伤害、闪避窗口、木系恢复和首领抗控数值需要团队实际试玩调优。
- 画面仍是 Canvas 程序绘制角色与特效，没有逐帧美术与独立音效文件；音效目前由浏览器合成，默认关闭。
- 旧存档保持原格式；只覆盖了已有数据的读取与规则测试，发布前建议备份 `instance/daoblade.sqlite3` 后再用真实玩家存档复测。
- 项目仍是单机 Web 原型；本轮没有账号、联机、桌面安装包或新地图系统。
