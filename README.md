# 本命剑：八荒五行

**DaoBlade: Fivefold Path** 是一款像素风横版修仙动作游戏原型。玩家使用相同的劈砍、格挡和远程剑气进入五行秘境，通过永久镶嵌随机灵珠，在八卦修行图上形成不同的战斗流派。

## 当前已实现

- Canvas 横版移动、跳跃与镜头跟随
- 劈砍、普通格挡、完美格挡、远程剑气
- 道法技能，任一八卦路线达到第三层后解锁
- 金、木、水、火、土五个主题秘境
- 每个秘境包含两种普通敌人与一个首领
- 五行灵珠随机掉落，一阶、二阶、三阶拥有不同初始词条数量
- 灵珠战斗经验、升级与追加词条
- 八条卦象路线，每条包含入门、化境、道法三层
- 已镶灵珠不能取下、替换或移动，后端会再次校验
- 五行主属性、副属性与基础战斗数值计算
- SQLite 单机存档，网络接口失败时保留浏览器备用存档
- 键盘和触屏操作界面
- 三段劈砍输入缓冲、短闪避、跳跃宽容、格挡后主动反击
- 五种主修分别改变劈砍、格挡和剑气；副修提供少量补充效果
- 镶珠前后五行与招式预览，以及不会写入正式存档的练功场
- 暂停、快速重试、自定义按键、可关闭的轻微震屏与可选音效

`docs/v0.2.0版本更新规划.md` 是开发规划，不代表该版本已经正式发布。实现与验证情况见 `docs/v0.2.0代码实施与交接.md`。

## 环境要求

- Windows 10/11
- Python 3.11 或更高版本
- 推荐 VS Code 或 Codex

项目已经在 `.venv` 中配置 Python 3.12。若需要重新创建环境，请使用本机 Python 3.11+。


## 操作

| 按键 | 动作 |
|---|---|
| A / D | 左右移动 |
| W / Space | 跳跃；巽卦化境后可二段跳 |
| J | 劈砍 |
| K | 格挡；受击前短暂按下触发完美格挡 |
| L | 消耗剑意释放远程剑气 |
| Q | 释放已经解锁的道法 |
| Shift | 短闪避，前段可避开攻击 |
| Esc | 暂停、重新挑战、退出和按键设置 |

完美格挡后按 J 才会主动反击。战斗中按“暂停”可修改按键、开关轻微震屏与音效。音效默认关闭。

## 修行规则

1. 玩家初始五行数值均为 1。
2. 秘境结束后获得随机品阶和随机词条的五行珠。
3. 灵珠可以留在珠匣中，镶嵌前能够预览卦位效果。
4. 灵珠必须从八卦中心向外依次镶嵌。
5. 镶嵌确认后不能取下或移动。
6. 已镶灵珠在每次闯关后获得经验，低阶珠也能升级并补充词条。
7. 五行最高值明确领先时成为主属性，第二高明确领先时成为副属性；并列时对应属性为“未定”，战斗也不会获得隐藏的主副加成。
8. 八卦修行页面可预览镶珠前后的五行和招式，点击“先试招”进入临时练功场。试招不写入正式存档。

## 当前限制

- 当前采用程序绘制的像素角色和敌人，尚未接入正式逐帧美术资源。
- 目前是单机存档，没有账号、联网排行或玩家交易。
- 关卡采用固定结构与程序化敌人配置，后续可以增加地图机关和更丰富的首领动作。
- 浏览器刷新会结束当前战斗，但已经结算和保存的修行进度不会丢失。
